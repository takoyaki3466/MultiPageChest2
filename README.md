# MultiPageChest（Minecraft 1.21.1 / Fabric・Forge・NeoForge）

5 ページ × 117 スロット（合計 585 スロット）を持つチェストを追加する MOD です。
CubeX2 氏による Minecraft 1.7.10 版 MultiPageChest（1.3.3）の機能を調査し、1.21.1 向けに**一から実装し直した**ものです。旧版のコードや画像は使用していません。

## 対応環境

| 項目 | バージョン |
|---|---|
| Minecraft | 1.21.1 のみ |
| Java | 21 |
| Fabric | Fabric Loader 0.16.9 以上、Fabric API（開発時 0.109.0+1.21.1） |
| Forge | 52.0.28 以上 |
| NeoForge | 21.1.80 以上 |

- Fabric 版は **Fabric API が必須**です。
- サーバーとクライアントの両方に導入してください。

## 機能

- **マルチページチェスト**（ID: `multipagechest:multipagechest`）
  - 1 ページ 13 列 × 9 行 = 117 スロット、全 5 ページ。1 スロット最大 64 個
  - 画面左右の「-」「+」ボタンでページ切替（最初と最後のページの間は循環）。画面右下に「現在ページ / 5」を表示
  - 右下の赤いスロット（ゴミ箱）に置いたアイテムは消滅します
  - Shift+クリック: チェスト → インベントリ（ホットバー優先）、インベントリ → 表示中のページ（入りきらなければ以降のページ）
  - 上に不透過ブロックや座った猫があると開けません
  - 壊すと中身はすべてその場にドロップします（ブロックに中身は保持されません）
  - バニラのチェストと同様に蓋が開閉し、開閉音が鳴ります
- **レシピ**（作業台）

  ```
  ダイヤ   チェスト ダイヤ
  チェスト  (空)    チェスト
  ダイヤ   チェスト ダイヤ
  ```

- クリエイティブタブ「機能的ブロック」に追加されます。
- 斧で効率よく回収できます。

## 1.7.10 版との違い

| 項目 | 1.7.10 版 | この版 |
|---|---|---|
| クリエイティブタブ | 装飾ブロック | 機能的ブロック（1.21.1 のバニラチェストと同じ） |
| ページ切替の通信 | 独自パケットでページ番号と座標を送信（サーバー側で未検証） | バニラのコンテナボタン通信。サーバーが現在ページを管理し、クライアントからはボタン ID のみ受け付ける |
| ページ切替時の手持ちアイテム | 画面を開き直す方式 | 同じ画面のまま切り替えるため、手持ちのアイテムを別ページへ運べる |
| ダブルクリックでの一括回収 | 非表示ページからも回収（と推定） | 表示中のページとインベントリのみ |
| アイテム表示 | 3D チェストモデル | 直方体モデル（蓋の段差・錠の立体なし） |
| Inventory Tweaks 連携 | あり | なし（1.21.1 向けの連携先を確認できないため） |
| 画像 | 旧版の画像 | 新規作成（`tools/generate_textures.py`） |

詳細な解析結果は [docs/legacy-analysis.md](docs/legacy-analysis.md)、設計は [docs/design.md](docs/design.md) を参照してください。

## ビルド

```bash
./gradlew build
```

各ローダーの jar は `multipagechestSrc/<loader>/build/libs/` に出力されます（このリポジトリでは未実行）。

## プロジェクト構成

```
multipagechestSrc/
├── common/    ローダー非依存のコードとリソース（ブロック、収納、メニュー、画面、描画、データ）
├── fabric/    Fabric 用の登録とエントリーポイント
├── forge/     Forge 用の登録とエントリーポイント
└── neoforge/  NeoForge 用の登録とエントリーポイント
docs/          旧版の解析結果、設計、静的チェックの記録
tools/         テクスチャ生成スクリプト
```

## 既知の制約・未確認事項

- ビルド、コンパイル、ゲーム内での動作確認は未実施です。
- 1.7.10 版のワールドデータからの移行には対応していません。
- ホッパー等による搬入・搬出は、バニラの `Container` としての動作に依存しており、各ローダー上での動作は未確認です。
- 翻訳は英語（`en_us`）のみです。
